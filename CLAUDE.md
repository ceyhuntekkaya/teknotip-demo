## Commands

- `npm run dev` — Next.js dev server on :3000 (needs the Spring backend at `API_URL`, default `http://localhost:8080/api`; copy `.env.local.example` to `.env.local`)
- `npm run build` / `npm start` — production build (`output: "standalone"`)
- `npm run lint` — ESLint (flat config; `lib/api/generated/**` is ignored)
- `npm test` — Vitest, runs only `lib/**/*.test.ts` in a node environment
- Single test: `npx vitest run lib/money.test.ts` or `npx vitest run -t "test name"`
- `npm run generate:api` — regenerate the API client with Orval from the running backend's OpenAPI spec (`http://localhost:8080/api/v3/api-docs`)
- Docker: see `document.txt` for the `docker buildx` command; `API_URL` is a build arg (defaults to production `https://teklifapi.genixo.ai/api`)

## What this is

A Turkish-language front end for a medical-equipment quoting tool (Teknotip, "teklif" = quote). It is a thin Next.js (App Router, React 19, Tailwind v4) client over a separate Spring Boot API. Most business logic, persistence and the AI quote chat (`chatWithQuote`) run in the backend. UI text and error messages are in Turkish, so keep new user-facing strings in Turkish.

## Architecture

### API client (Orval-generated)
- `lib/api/generated/{endpoints,model}` is generated by `orval.config.ts` and committed. **Do not hand-edit it**; change the backend and run `npm run generate:api` instead. Endpoints for which no generated client exists yet are hand-written against `customFetch` (for example `lib/api/organized-products.ts` and `lib/api/users.ts`).
- Every generated call goes through `customFetch` (`lib/api/fetcher.ts`) and returns `{ data, status, headers }` without throwing on HTTP errors. Callers branch on `status` (e.g. `res.status === 200 ? res.data.content : []`). Use `lib/api/errors.ts` (`apiErrorMessage`) for error display.
- `lib/api/map.ts` converts `*Response` → `*Request` shapes (e.g. `quoteToRequest`) for update calls. When generated models gain fields, update these mappers.

### Request routing and auth
- The generated base URL is `/backend`. In the browser, requests hit `app/backend/[...path]/route.ts`, which streams them to `API_URL`. On the server, `resolveApiUrl` (`lib/api/config.ts`) strips `/backend` and calls `API_URL` directly.
- Auth uses JWT access/refresh tokens stored in httpOnly cookies (`lib/auth/cookies.ts`). `proxy.ts` is the Next 16 replacement for middleware. It injects `Authorization: Bearer` on `/backend/*` and redirects unauthenticated users away from private routes. **When you add a new private page, add it to both `isPrivate` and `config.matcher` in `proxy.ts`.**
- Server-side token access uses a binding pattern: `lib/auth/session.ts` (server-only) calls `bindServerAuth` so that `customFetch` can read cookies without importing `next/headers` into client bundles. Server components must import API functions from `lib/api/server.ts`, which imports the session module for this side effect. Client components import generated endpoints directly.
- On a 401, `customFetch` refreshes once (server: directly with the refresh token; client: `POST /api/auth/refresh`, which rewrites cookies) and then redirects to `/api/auth/expire-session`. Cookies can only be written in Server Actions or Route Handlers (`lib/auth/login.ts` and `logout.ts` are `"use server"`), not during RSC render.

### Pages
The pattern is `app/<section>/page.tsx`: an async server component (`dynamic = "force-dynamic"`) loads lists through `lib/api/server.ts` and passes them to a `"use client"` browser/editor in `components/<domain>/`. Core flow: `/teklif` (`app/teklif/quote-bench.tsx`) is the voice + chat quote builder. The browser records audio, VAD/utterance logic is in `lib/stt/*`, `app/api/teklif/transcribe/route.ts` proxies to a Whisper STT service (`STT_URL`), and the transcript goes to the backend `chatWithQuote`. Chat workspace state is kept in localStorage (`lib/quote/workspace.ts`, versioned key; bump `QUOTE_WORKSPACE_VERSION` when changing its shape).

### Documents and money
- Quote PDFs are rendered client-side with `@react-pdf/renderer` (`components/pdf/*`, styles/fonts/format in `lib/pdf/*`, IBM Plex fonts in `public/fonts`, company info in `app/data/company.json`). `amount-in-words.ts` writes totals in Turkish words.
- Excel export uses a dynamically imported `exceljs` (`lib/export/*`). Both `exceljs` and `@react-pdf/renderer` are listed in `serverExternalPackages`.
- Money formatting and currency units are handled in `lib/money.ts` (TRY/USD/EUR/GBP; `TL` is treated as an alias for TRY).- `lib/catalog/*` holds the local product/option-group model (types, rules, pricing, linting) used by the catalog editor and quote views.

Path alias: `@/*` maps to the repo root.
